# Задача 6.3.2 — Мониторинг ошибок через Sentry

## Описание
Подключить Sentry к FastAPI-приложению и возвращать идентификатор события ошибки в заголовке ответа.

## Задачи

### 1. Установка и конфигурация
```bash
pip install "sentry-sdk[fastapi]"
```
- Получить DSN проекта и передать его через переменную окружения `SENTRY_DSN` (не хардкодить).
- Инициализировать SDK при старте:
```python
sentry_sdk.init(dsn=os.getenv("SENTRY_DSN"), traces_sample_rate=1.0)
```

### 2. Диагностический маршрут
- Добавить `GET /sentry-debug`, намеренно выбрасывающий исключение (например, деление на ноль). Убедиться, что событие появляется в Sentry.

### 3. Глобальный обработчик ошибок
- `@app.exception_handler(Exception)` для неперехваченных ошибок.
- Зафиксировать исключение: `event_id = sentry_sdk.capture_exception(exc)`.
- Вернуть JSON с безопасным текстом ошибки и заголовком `X-Error-Event-Id: <event_id>`.

### 4. Контекст и теги *(опционально)*
- `sentry_sdk.set_context(...)`, `sentry_sdk.set_tag(...)` (например, `user_id`, `endpoint`, `environment`).

## Критерии приёмки
- SDK инициализирован, DSN берётся из окружения.
- Есть маршрут `/sentry-debug`, событие появляется в Sentry.
- Глобальный обработчик фиксирует исключение и возвращает заголовок `X-Error-Event-Id`.

> При необходимости используйте специальное ПО для доступа к потенциально недоступному в РФ sentry.io.

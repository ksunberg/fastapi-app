# Задача 6.2.1 — Валидация данных и обработка ошибок

## Описание
Реализовать проверку данных запроса через Pydantic и пользовательскую обработку ошибок валидации.

## Задачи
1. Создать приложение с эндпоинтом, принимающим JSON с данными пользователя.
2. Определить Pydantic-модель для валидации входящих данных:

```python
class User(BaseModel):
    username: str
    age: conint(gt=18)
    email: EmailStr
    password: constr(min_length=8, max_length=16)
    phone: Optional[str] = 'Unknown'
```

   - `conint(gt=18)` — int с ограничением «больше 18»;
   - `EmailStr` — проверка формата e-mail;
   - `constr(min_length=8, max_length=16)` — строка с ограничением длины;
   - `Optional[str]` — необязательное поле со значением по умолчанию.

3. Реализовать пользовательский обработчик ошибок валидации через `@app.exception_handler` для информативных ответов.
4. Протестировать обработку, отправляя запросы с неверными данными, и убедиться, что ответы содержат корректные статусы и сообщения.

> Можно использовать `fastapi.testutil.testclient.TestClient` для тестовых запросов.

# Задача 6.1.2 — Логирование ошибок через Loguru

## Описание
Подключить Loguru, настроить структурированное логирование и глобальный обработчик всех ошибок.

## Задачи
1. Установить библиотеку:
```bash
pip install loguru
```
2. Взять стартовый код приложения (маршруты `/ok`, `/error`, `/boom`) и добавить глобальный обработчик `@app.exception_handler(Exception)`, который:
   - перехватывает все необработанные ошибки (включая `CustomAppError`);
   - пишет структурированные JSON-логи (рекомендуется `serialize=True`);
   - добавляет контекст запроса: `request.method`, `request.url.path`;
   - для пользовательских ошибок возвращает соответствующий статус (например, `exc.code`), для остальных — 500 с безопасным сообщением без утечки деталей.

## Настройка логирования
- Зарегистрировать sink-и через `logger.add(...)` для stdout и файла (с `rotation`/`retention`).
- Использовать `logger.bind(...)` для добавления контекста.

## Проверка работы
- `GET /ok` — успех без ошибок.
- `GET /error` — выбрасывается `CustomAppError`; проверить тело ответа и запись в логах.
- Любая непредвиденная ошибка — статус 500, а стек-трейс попадает в логи.

> Материалы: [Loguru](https://loguru.readthedocs.io/), [репозиторий Loguru](https://github.com/Delgan/loguru).

# Задача 3.1.1 — Создание пользователя

## Описание
Создать POST-эндпоинт, принимающий данные пользователя с валидацией.

## Поля модели `UserCreate`
- `name` (str) — имя пользователя, обязательно.
- `email` (str) — адрес электронной почты, обязателен и должен быть валидным.
- `age` (int) — возраст, необязательно; если указан — должно быть положительное целое число.
- `is_subscribed` (bool) — флаг подписки на рассылку, необязательно.

## Задачи
1. Определить Pydantic-модель `UserCreate` с соответствующими правилами проверки.
2. Создать POST-маршрут `/create_user`, принимающий JSON по модели `UserCreate`.
3. Вернуть полученную информацию о пользователе.

## Пример
**Запрос:**
```json
{
    "name": "Alice",
    "email": "alice@example.com",
    "age": 30,
    "is_subscribed": true
}
```

**Ответ:**
```json
{
    "name": "Alice",
    "email": "alice@example.com",
    "age": 30,
    "is_subscribed": true
}
```

> Протестируйте реализацию через curl, Postman или любой другой API-клиент.

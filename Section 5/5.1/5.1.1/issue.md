# Задача 5.1.1 — SQLite: таблица users и регистрация

## Описание
Создать таблицу `users` в SQLite и эндпоинт регистрации пользователей.

## Задачи
1. Создать таблицу `users` с полями:
   - `id` (INTEGER, первичный ключ с автоинкрементом);
   - `username` (TEXT, обязательное);
   - `password` (TEXT, обязательное).
2. В `database.py` настроить подключение к базе данных (как в лекции).
3. Написать скрипт создания таблицы (с `IF NOT EXISTS`) и запустить его один раз.
4. В `main.py` создать Pydantic-модель `User` (`username`, `password`).
5. Добавить `POST /register`, который:
   - подключается к БД через `get_db_connection()`;
   - вставляет данные в таблицу `users`;
   - фиксирует изменения (`commit()`) и закрывает соединение;
   - возвращает `{"message": "User registered successfully!"}`.

## Тестирование
```bash
curl -X 'POST' 'http://127.0.0.1:8000/register' \
  -H 'Content-Type: application/json' \
  -d '{"username": "test_user", "password": "12345"}'
```

> Требования: использовать синтаксис из лекции (без SQLAlchemy); пароль хранить в открытом виде. Проверить создание таблицы, успешный ответ и появление данных в БД (например, через DB Browser for SQLite).

# Задача 5.1.3 — Связь таблиц users и todos

## Описание
Связать таблицы `users` и `todos` отношением «один-ко-многим» и реализовать каскадное удаление.

## Задачи
1. **Модификация схемы БД:**
   - добавить в `todos` поле `user_id` (INTEGER);
   - создать внешний ключ `todos.user_id → users.id` с каскадным удалением:

```sql
ALTER TABLE todos ADD COLUMN user_id INTEGER REFERENCES users(id) ON DELETE CASCADE;
```

2. **Обновление CRUD для Todo:**
   - все эндпоинты Todo (GET, POST, PUT, DELETE) должны принимать/возвращать `user_id`;
   - проверять существование пользователя при создании/обновлении задач.

3. **Новый эндпоинт `DELETE /users/{user_id}`:**
   - при удалении пользователя автоматически удаляются его задачи (`ON DELETE CASCADE`);
   - ответ: `{"message": "User and associated todos deleted"}`.

## Тестирование
- Создать пользователя и несколько связанных задач.
- Вызвать `DELETE /users/{id}` и убедиться, что удаляется и пользователь, и все его задачи из БД.

## Критерии успеха
- Связь работает на уровне БД.
- Удаление пользователя очищает все его задачи.
- Все эндпоинты корректно работают с `user_id`.

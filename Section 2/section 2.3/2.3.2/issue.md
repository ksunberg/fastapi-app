# Задача 2.3.2 — Валидация отзывов

## Описание
Расширить обработку отзывов: добавить валидацию данных и блокировку нежелательных слов.

## Задачи
1. Определить модель `Feedback` с ограничениями:
   - `name` — строка, от 2 до 50 символов
   - `message` — строка, от 10 до 500 символов
2. Добавить кастомную валидацию поля `message`: отклонять отзывы, содержащие слова **«редиска», «бяка», «козявка»** в любых падежах. При нахождении выбрасывать `ValueError("Использование недопустимых слов")`.
3. Реализовать POST-маршрут `/feedback`:
   - принимает JSON по модели `Feedback`;
   - при успехе сохраняет данные в список `feedbacks`;
   - возвращает `{"message": "Спасибо, {name}! Ваш отзыв сохранён."}`.

## Пример
**Валидный запрос:**
```json
{
    "name": "Анна",
    "message": "Этот курс заставляет меня напрячься, но я все равно его пройду!"
}
```

**Ответ:**
```json
{
    "message": "Спасибо, Анна! Ваш отзыв сохранён."
}
```

**Некорректный запрос (HTTP 422):**
```json
{
    "name": "А",
    "message": "тут сплошные редиски кругом, житья совсем не дают"
}
```

> Понадобятся знания о `min_length`, `max_length`, `@field_validator` и регулярных выражениях. Проверьте реализацию, отправляя корректные и ошибочные отзывы.

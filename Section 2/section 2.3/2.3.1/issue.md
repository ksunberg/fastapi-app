# Задача 2.3.1 — Отзывы пользователей

## Описание
Добавить эндпоинт для отправки отзывов и их хранения в памяти.

## Задачи
1. Определить Pydantic-модель `Feedback` с полями:
   - `name` (str)
   - `message` (str)
2. Создать POST-маршрут `/feedback`, принимающий JSON по модели `Feedback`.
3. Обработать входящий отзыв и вернуть сообщение об успешном завершении.
4. Сохранять все отзывы в список или хранилище данных.

## Пример
**Запрос:**
```json
{
    "name": "Alice",
    "message": "Отличный курс, я многое узнаю, а также закрепляю знания на практике!"
}
```

**Ответ:**
```json
{
    "message": "Feedback received. Thank you, Alice."
}
```

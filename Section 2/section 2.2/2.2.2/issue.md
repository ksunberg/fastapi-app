# Задача 2.2.2 — Проверка на взрослого

## Описание
Добавить POST-эндпоинт, который принимает данные пользователя и определяет, является ли он взрослым.

## Задачи
1. Определить Pydantic-модель `User` с полями:
   - `name` (str)
   - `age` (int)
2. Создать POST-маршрут `/user`, принимающий JSON по модели `User`.
3. Вычислить поле `is_adult` (`age >= 18` — True, иначе False).
4. Вернуть данные пользователя вместе с полем `is_adult`.

## Пример
**Запрос:**
```json
{
    "name": "John Doe",
    "age": 25
}
```

**Ответ:**
```json
{
    "name": "John Doe",
    "age": 25,
    "is_adult": true
}
```

> Протестируйте реализацию через curl, Postman или любой другой API-клиент.

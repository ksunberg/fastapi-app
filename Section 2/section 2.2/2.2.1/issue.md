# Задача 2.2.1 — Pydantic-модель User

## Описание
Расширить приложение FastAPI: добавить Pydantic-модель пользователя и эндпоинт, возвращающий данные о пользователе.

## Задачи
1. В файле `models.py` определить Pydantic-модель `User` с полями:
   - `name` (str)
   - `id` (int)
2. Импортировать модель в основной файл приложения и создать экземпляр:
   - `name`: "John Doe"
   - `id`: 1
3. Реализовать GET-маршрут `/users`, возвращающий JSON с данными пользователя.

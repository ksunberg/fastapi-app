# Задача 2.1.3 — Калькулятор

## Описание
Создать POST-эндпоинт, который принимает два числа и возвращает их сумму.

## Задачи
1. Реализовать POST-маршрут `/calculate` с входными числами `num1` и `num2`.
2. Вернуть ответ с суммой двух чисел.

## Пример
**Запрос:** `/calculate` с `num1=5` и `num2=10`

**Ответ:**
```json
{"result": 15}
```

> Примечание: для тестирования можно использовать любой удобный способ запуска приложения.

# Задача 4.2.1 — JWT-аутентификация (PyJWT)

## Описание
Реализовать аутентификацию на основе JWT с помощью библиотеки `PyJWT`.

## Задачи
1. Создать `POST /login` с JSON-полезной нагрузкой (`username`, `password`) и аутентифицировать пользователя.
2. При валидных учётных данных сгенерировать JWT-токен со сроком действия и вернуть его.
3. При неверных данных вернуть соответствующий ответ об ошибке.
4. Создать защищённый эндпоинт `GET /protected_resource`, требующий токен в заголовке `Authorization`.
5. Проверять токен для каждого запроса к `/protected_resource`: при валидном токене разрешить доступ, иначе вернуть ошибку (недействительный, истёкший или отсутствующий токен).

> Можно использовать функцию-заглушку `authenticate_user(username, password) -> bool` (например, на `random.choice`).

## Пример
**Запрос:**
```json
{
  "username": "john_doe",
  "password": "securepassword123"
}
```

**Ответ (200 OK):**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**Ответ (401 Unauthorized):**
```json
{
  "detail": "Invalid credentials"
}
```

> ⚠️ Это упрощённая учебная задача. В реальных системах учитывайте механизмы обновления и отзыва токенов и следуйте рекомендациям по безопасности.

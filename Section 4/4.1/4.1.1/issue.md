# Задача 4.1.1 — Базовая аутентификация

## Описание
Реализовать защищённую базовой аутентификацией конечную точку `/login`.

## Задачи
1. Создать `GET /login`, который аутентифицирует пользователя по учётным данным.
2. Проверять корректность имени пользователя и пароля через зависимость.
3. При неверных или отсутствующих учётных данных возвращать `HTTPException` со статусом 401.
4. При успешной аутентификации возвращать секретное сообщение: **"You got my secret, welcome"**.
5. Сначала авторизоваться с неправильными данными, затем с корректными. Чтобы браузер повторно показывал приглашение на ввод логина, изучите, как добавить заголовок `WWW-Authenticate`.

# Задача 2.1.1 — Первое FastAPI-приложение

## Описание
Создать простое FastAPI-приложение, которое по адресу `/` возвращает JSON-ответ.

## Задачи
1. Создать файл `app.py` и написать код приложения FastAPI.
2. По корневому URL `/` возвращать ответ `{"message": "Добро пожаловать в моё приложение FastAPI!"}`.
3. Запустить приложение через `uvicorn` в режиме разработки (с автоперезагрузкой).
4. Проверить ответ в браузере.

## Дополнительно
- Не останавливая uvicorn, изменить текст ответа на `{"message": "Авторелоад действительно работает"}` и убедиться, что браузер показывает новое сообщение.
- Изменить имя переменной приложения и убедиться, что uvicorn теперь требует другой аргумент для запуска.

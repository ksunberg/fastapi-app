# Задача 7.3.1 — Интеграционные тесты (TestClient + БД)

## Описание
Написать интеграционные тесты для FastAPI-приложения с подключением к базе данных, используя `TestClient` и pytest.

## Задачи
1. Настроить приложение FastAPI с интеграцией с БД (SQLite, PostgreSQL или MySQL).
2. Подготовить тестовую среду: отдельную тестовую базу данных, которую приложение использует во время интеграционного тестирования.
3. Реализовать минимум три эндпоинта с разной функциональностью: регистрация пользователей, извлечение данных, обновление данных.
4. Написать интеграционные тесты на pytest и `TestClient`, покрывающие положительные сценарии и сценарии потенциальных ошибок.
5. Убедиться, что тесты корректно взаимодействуют с приложением и БД, выполняя операции CRUD.

> Примечание: используйте подходящий database engine (SQLite/PostgreSQL). Сбрасывайте тестовую базу перед каждым тестом, чтобы обеспечить «чистый лист» для каждого тестового примера.

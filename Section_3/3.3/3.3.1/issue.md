# Задача 3.3.1 — Работа с заголовками запроса

## Описание
Создать эндпоинт, который извлекает и возвращает заголовки из входящего запроса.

## Задачи
1. Создать эндпоинт `GET /headers`.
2. Извлечь заголовки:
   - `User-Agent` — строка пользовательского агента клиента;
   - `Accept-Language` — предпочтительный язык клиента.
3. Вернуть JSON с извлечёнными заголовками и их значениями.
4. При отсутствии обязательных заголовков вернуть ошибку 400 (через `HTTPException`).
5. *(Необязательно)* Проверять формат `Accept-Language` (например, `en-US,en;q=0.9,es;q=0.8`) и возвращать 400 при некорректном формате.

## Пример
**Запрос:**
```
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36
Accept-Language: en-US,en;q=0.9,es;q=0.8
```

**Ответ:**
```json
{
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36",
    "Accept-Language": "en-US,en;q=0.9,es;q=0.8"
}
```

> Подсказка: используйте `request.headers` или класс `Header`. Протестируйте обработку ошибок, отправляя запросы без требуемых заголовков или с неверным форматом.
